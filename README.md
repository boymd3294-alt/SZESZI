# SZESZI

## Szigeti Endre Technikum közösségi és tanulási alkalmazása

A **SZESZI** egy modern, iskolai közösségi és tanulást segítő platform.

A célja, hogy a diákok és tanárok egy helyen tudjanak kommunikálni, kérdéseket feltenni, válaszolni, bejegyzéseket megosztani, csoportokban dolgozni, tananyagokat használni és az iskolai híreket követni.
